# pulsehash

Pulse structured JSON hash payloads without a heavyweight toolkit.

**Site:** https://theworker02.github.io/pulsehash/

## Install / run

```bash
git clone https://github.com/theworker02/pulsehash.git
cd pulsehash
node src/cli.js
node --test
```
